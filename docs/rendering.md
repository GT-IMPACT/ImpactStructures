# Рендер голограмм

## Angelica

Dev-клиент запускается с [Angelica 2.2.43](https://github.com/GTNewHorizons/Angelica/releases/tag/2.2.43)
и GTNHLib 0.11.52. UniMixins 0.3.1 уже подключён проектом.
Angelica остаётся опциональным клиентским модом: на сервере и у потребителей
библиотеки обязательной зависимости нет. Интеграция сообщает Angelica о видимых
текстурах голограммы, чтобы оптимизация анимаций не замораживала их.

```sh
./gradlew runClient
./gradlew runClient -Pangelica=false
```

Для обычной сборки игры установите release JAR Angelica и GTNHLib в клиентскую
папку `mods`; Gradle подключает их только в dev-клиент.
По [документации Angelica](https://github.com/GTNewHorizons/Angelica/blob/2.2.43/README.MD),
OptiFine, FastCraft и BetterFPS с ней несовместимы.

## Оптимизации

- Текстуры блоков, заливка служебных маркеров и цветные рамки используют общий
  атлас. Маркер больше не завершает пакет ради переключения `GL_TEXTURE_2D`.
  Сохранены порядок от дальних подсказок к ближним и последовательность слоёв.
- Лимит пакета увеличен с 4096 до 32760 вершин, кратного трём. Например, для
  10000 видимых подсказок «текстура + ошибка» без цветной рамки достаточно около
  22 пакетов заливки вместо примерно 20000. Это расчёт числа вызовов, не замер FPS.
- Проверка видимости выполняется один раз за кадр; три прохода контуров обходят
  только видимые служебные маркеры.
- Освещение текстуры и цветной рамки запрашивается один раз за клиентский тик.
  Полнояркая заливка маркеров не читает освещение мира.
- При сортировке расстояние вычисляется один раз для каждой подсказки.
  Уведомление об использовании текстуры отправляется один раз за кадр на объект иконки.
- Поиск и замена подсказки по координатам выполняются через хеш-таблицу, включая
  массовое применение маркеров ошибок и цветов.

## Проверка в игре

На одном сохранении повторить большую голограмму с одинаковыми настройками,
разрешением и положением камеры. Сравнить кадры с выключенной голограммой,
с обычными подсказками и с большим числом ошибок; затем повторить без Angelica.
На время замеров отключить VSync и ограничитель FPS, держать окно в фокусе.
Проверить движение камеры, вид через стены, анимацию текстур, смену освещения,
перезагрузку ресурсов, исчезновение и повторное создание голограммы.

Для CPU-профиля использовать секции `HintParticle/Prepare` и `HintParticle/Draw`.
Сохраняются затраты на прозрачные поверхности и три прохода контуров ошибок;
Angelica не переносит эту геометрию автоматически в кеш мешей чанков.
Автоматические тесты проверяют UV белого участка атласа, отсутствие чтения света
для заливки маркеров, обновление кеша освещения и обработку незагруженных чанков.
